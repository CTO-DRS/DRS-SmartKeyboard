# لوحة مؤشرات الجودة (QUALITY_DASHBOARD.md)

- **المرحلة:** خريطة الطريق الكبرى — المرحلة 1، المهمة 5.
- **المبدأ (ADR 0004):** كل مؤشر يُقاس محليًا من بيانات حقيقية، ولا يخرج من
  الجهاز إلا بمشاركة يدوية صريحة من المستخدم. لا Crashlytics، لا تتبع، لا
  خدمات غوغل داخل عملية لوحة مفاتيح.

## 1. مصادر المؤشرات (كلها موجودة اليوم)

| المصدر | المؤشر | أين يُعرض للمستخدم |
|---|---|---|
| `DrsPerformance.recordKeyLatency` | زمن معالجة المفتاح: متوسط، p50/p95، أقصى (ميكروثانية، نافذة 256) | شاشة الأداء |
| `DrsPerformance.memorySnapshot` | كومة Java المستخدمة/القصوى + الكومة الأصلية | شاشة الأداء |
| `DrsDailyStats` | ضغطات/كلمات/وقت كتابة يوميًا | شاشة الإحصاءات |
| `DrsEventLog` (حلقة 200 مطهّرة) | أحداث الأنظمة والأخطاء | شاشة التشخيصات |
| `DrsCrashReports` (سجل JSON محدود 20) | بصمات الأعطال + معدل الأعطال لكل جلسة | شاشة التشخيصات |
| `DrsStore` | حجم ملف الحالة الفعلي على القرص | شاشة الأداء |

## 2. مؤشرات النجاح المرحلية (المرحلة 1 من الخريطة)

| المؤشر | الهدف | طريقة القياس |
|---|---|---|
| نسبة خلو الأعطال (تقدير محلي) | ≥ 99.5% | `DrsCrashReports.crashRatePerSession()` ≤ 0.005 عبر جلسات المختبرين |
| زمن CI الكامل | < 10 دقائق | زمن سير `android.yml` على GitHub |
| تغطية الاختبارات | مسار ≥85% | تقرير JaCoCo في CI (docs/COVERAGE.md) |
| حجم APK (release، R8) | رقابة انحدار | مقارنة `SHA256SUMS` والحجم مع كل إصدار |

## 3. كيف تتغذى لوحة الفريق (بلا تتبع)

1. **مختبرون متطوعون** يصدّرون تقرير الأعطال/التشخيصات من شاشة التشخيصات
   ويشاركونه في بلاغ GitHub (التصدير يدوي 100% — يرى المستخدم المحتوى قبل الإرسال).
2. **الفريق** يلخص بصمات الأعطال المتكررة (`stackHash` متطابقة = نفس الصنف)
   في جدول أعلى الأعطال داخل النقاش الأسبوعي.
3. **تقرير جودة ربع سنوي** (بند المرحلة 3: تقرير الشفافية) يُنشر علنًا: عدد
   الأعطال المبلّغة، أصلحها، معدل خلو الأعطال التقديري — أرقام مجمعة بلا أي
   معرف مستخدم.

## 4. لماذا لا توجد «لوحة حية» مركزية اليوم؟

قرار صريح في ADR 0004: أي لوحة حية عبر سحابة تتطلب إرسال بيانات — وهذا يناقض
عقد الخصوصية قبل أن يكتمل «وضع الخصوصية المطلق» (المرحلة 3: حظر شبكي مُثبت
تقنيًا). حين يكتمل ذلك الوضع وتُفتح البنية الذاتية (المرحلة 5)، تُعاد دراسة
جمع اختياري opt-in عبر إقرار ADR مستقل — بالأدلة لا بالوعود.

## 5. حدود التقدير المحلي (الصدق الرقمي)

- `crashRatePerSession` يقيس **الجلسات المسجلة محليًا فقط** — إجمالي عدد
  الجلسات الفعلي (كل المستخدمين) غير معروف محليًا، فالمؤشر مؤشر مختبرين لا
  مؤشر سوق، ويُقدَّم بذلك الوصف دائمًا.
- نافذة الأداء 256 عينة هي نافذة الحاضر — الأرقام المجمعة على مدى أيام تأتي
  من `DrsDailyStats` (ملخصات) لا من إعادة تشغيل الحلقة.
