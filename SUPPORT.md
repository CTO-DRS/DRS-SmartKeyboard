## قبل فتح بلاغ | Before opening an issue

1. ابحث في البلاغات المفتوحة والمغلقة عن مشكلتك. | Search open/closed issues first.
2. حدد الإصدار (`الإعدادات ← حول` أو رقم APK). | Note your version (Settings → About, or the APK name).
3. إن كان عطلًا متكررًا، أرفق تقرير الأعطال (انظر أدناه). | For recurring crashes, attach a crash report (below).

## تقرير الأعطال: خصوصية أولًا | Crash reports: privacy first

- السجل **محلي بالكامل** ولا يخرج من جهازك تلقائيًا — أبدًا. |
  The log is **fully local** and never leaves your device automatically — ever.
- المحتوى مطهّر: اسم صنف الاستثناء وبصمة المكدس فقط، بلا أي نص كتبته أو رسالة
  خطأ. | Content is sanitized: exception class + stack fingerprint only, never
  typed text or error messages.
- التصدير يدوي: **شاشة التشخيصات ← تصدير سجل الأعطال** ثم شاركه مع بلاغك
  أنت بنفسك. | Export is manual: **Diagnostics → export crash log**, then you
  share it with your issue yourself.

## قالب البلاغ | Issue template

```
الإصدار / Version: DRS Smart Keyboard vX.Y.Z
الأجهزة / Device: model + Android version
الخطوات / Steps to reproduce: 1… 2… 3…
المتوقع / Expected: …
الفعلي / Actual: …
تقرير العطل / Crash report: (مرفق إن وُجد / attached if any)
```
